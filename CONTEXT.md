# ContextSwitcher

ContextSwitcher helps a person preserve and resume task contexts made up of related desktop windows and productivity state.

## Language

**Display Language**:
The language ContextSwitcher uses for app-owned user-facing text. It does not alter user-authored content, external application names, paths, or developer-facing data.
_Avoid_: System language, content language

**System Language**:
The operating system locale consulted when a user has not explicitly chosen a Display Language. It does not override an explicit user choice.
_Avoid_: Default language
