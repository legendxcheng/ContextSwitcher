# Triage Labels

将工程技能中的五种标准角色映射到本仓库的实际标签。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给自主 Agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提到某个角色时，使用对应的本仓库标签。
后续调整标签名称时，修改第二列。
