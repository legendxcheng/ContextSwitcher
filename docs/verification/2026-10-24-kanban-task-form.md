# 任务新建与编辑弹窗验收

日期：2026-10-24。范围为会话中确认的新建/编辑统一居中弹窗方案。

## 实现

- `TaskFormDialog` 替换创建表单与右侧编辑抽屉，统一标题、提示词、优先级；创建后关闭并刷新，不再自动进入编辑。
- `create_task` 接收可选 `promptJson`，一次 INSERT 保存全部字段；旧调用省略参数兼容 `{}`，不改变数据库结构。
- 提示词支持多行及文件/技能引用；候选 Portal 跟随光标并限制在窗口内。保存失败保留草稿并恢复表单焦点；保存中锁定编辑与关闭，阻止重复提交。
- 窗口级居中、720px 宽、自适应高度、正文滚动、固定头尾、焦点循环和入口焦点恢复。
