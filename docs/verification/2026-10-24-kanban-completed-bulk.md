## 已实现范围

- 完成列标题增加一键归档、一键删除图标，含中文/英文无障碍名称及悬停提示；空列禁用。
- 固定点击时当前项目已完成列的任务 ID 集合。归档直接执行，删除仅确认一次并显示数量及删除范围。
- Rust 后台线程逐项处理，每项独立事务重新核对项目、完成状态和未归档条件；已受理后台启动但业务 status 尚为 done 的任务也跳过。
- 归档共用现有未决操作及清理守卫，保留正文、快照、会话和审计。删除允许异常完成/派发状态，级联移除本地绑定/会话/目录，保留操作审计。两者均不查询或关闭 Herdr pane。
- 单项写入失败回滚该项并继续后续任务；结果显示成功、跳过、失败数量和逐项原因。成功项立即从本地列表移除，迟到列表不能恢复卡片。
- 批次内卡片防重复操作；其他任务及新建仍可操作。切换项目后旧结果不污染新看板。
