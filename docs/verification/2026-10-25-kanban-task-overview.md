日期：2026-10-25。范围：按需弹窗、当前导航 Workspace 汇总、完成时间持久化及今日计数。

## 已实现

- 侧栏项目标题旁仅增加「任务概况」入口；打开后展示三项总数及每个 Workspace 的待办、进行中、已完成、今日已完成。
- 状态计数与看板列一致，排除归档任务；准备中/待核实启动投影到进行中。
- 今日按本地自然日计算，包含已归档完成任务，排除删除、重新打开及完成日期未知的任务。旧库升级不从最后编辑时间推测完成时间。
- 完成与完成时间同条 SQL 保存；清理失败不撤销业务完成。关闭重试、修改标题和归档不改变完成时间；回到待办、成功派发或恢复开发清空时间。
- 仅弹窗打开时批量查询；前台 2 秒、启动通知、焦点及午夜刷新，合并请求并隔离旧范围/旧日期响应。失败显示重试，不显示零计数。
- 关闭按钮、Esc、遮罩关闭、焦点循环/恢复、背景 inert、项目名称跳转、长列表内部滚动与中英文文案。

- 从旧结构数据库启动，迁移 10 后旧 done 任务的 completed_at 仍为空。
- 3 个 Workspace（含空项目）的逐项目/总计与数据库一致；当天归档任务计入今日完成，但不计入看板完成列。
- 通过真实 IPC 完成、再次完成、编辑、移回待办、再次完成、归档与删除；检查 SQLite 时间字段和弹窗轮询后的数字变化。
