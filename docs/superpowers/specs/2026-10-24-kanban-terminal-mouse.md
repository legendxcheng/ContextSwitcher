# Kanban 终端滚轮与滚动步长

日期：2026-10-24。状态：已实现；验证结果与限制见 [验收记录](../../verification/2026-10-24-kanban-terminal-scroll.md)。来源：GitHub #21。

## Problem Statement

Kanban 右侧 xterm 终端的键盘可用，滚轮原先未连接到 Herdr。接入后，Codex CLI 中滚动幅度仍过小：一次较大的滚轮输入实测仅移动约一行。

用户最新决定：不再要求鼠标点击，只完成滚轮，并明显增大默认步长。本规格替代此前的点击交互范围。

## Solution

将滚轮接入当前任务的 Herdr 终端，默认一格约滚动六行，触控板小幅输入仍可累积并平滑响应。保留文字选择、键盘、字号调整、连接恢复和任务隔离。实现兼容已有 `terminal.scroll` 的控制接口，不要求为鼠标点击升级 Herdr。

## User Stories

1. 作为看板用户，我希望滚轮能查看更早的输出，以便直接在看板阅读任务内容。
2. 作为看板用户，我希望每格滚轮约移动六行，以便不必长时间反复滚动。
3. 作为看板用户，我希望向下滚动能回到当前内容，以便继续操作。
4. 作为 Codex CLI 用户，我希望应用接管滚轮时也获得足够的滚动幅度，以便浏览长回答。
5. 作为普通终端用户，我希望宿主历史回滚保持同样的滚动量，以便不同界面体验一致。
6. 作为触控板用户，我希望小幅像素增量可累积，以便细小手势不会全部丢失。
7. 作为看板用户，我希望改变滚动方向后立即按新方向移动，以便不残留上一方向的积累。
8. 作为看板用户，我希望快速滚动不会形成长时间排队，以便停止操作后界面及时停下。
9. 作为看板用户，我希望滚动只作用于终端，以便看板和页面不会同时移动。
10. 作为看板用户，我希望调整字号和面板宽度后步长仍合理，以便阅读体验稳定。
11. 作为多任务用户，我希望切任务或项目后丢弃旧滚动，以便其他任务不会误收输入。
12. 作为看板用户，我希望断线、重连和任务结束不会重放旧滚轮动作，以便恢复后状态可预期。
13. 作为看板用户，我希望文字选择、复制和键盘输入不受影响，以便继续使用既有交互。
14. 作为维护者，我希望真实 Windows 看板、Herdr 和 Codex CLI 能证明滚动行数变化，以便不把 IPC 成功误认为效果达标。

## Implementation Decisions

- 范围仅为终端组件、连接级滚轮控制器、前端 API、Tauri 终端命令和终端控制服务；不实现点击、拖动或移动事件转发。
- 浏览器行模式每单位对应两行；常见三行/120 CSS px 的滚轮一格对应六行。像素模式每 20 CSS px 对应一行；页模式按当前终端行数换算。步长不随字号漂移。
- 像素小数保留到下一事件，反向时清除旧方向积累；单批最多 24 行，队列最多 16 批，相邻同方向、位置和修饰键相同的滚动合并并封顶。避免无限积压，不对失败滚动自动重试。
- Herdr 在应用鼠标报告及 alternate-scroll 路径中，一条 `terminal.scroll` 仅转发一次事件，忽略其 `lines` 放大参数。因此后端在一次身份核验后，把请求行数写为有限批量的单行滚动命令，统一宿主历史和应用内部滚动量。
- IPC 仅接收连接 ID、方向、数量、字符坐标、修饰键及事件对应的终端网格尺寸，不接受任意 pane。后端复用任务/绑定/进程身份核验，拒绝过时连接、越界值和已失效尺寸。
- 前端在终端字符区捕获滚轮，阻止 xterm 本地滚动和外层页面重复处理；标题、内边距、分隔线不成为远端输入区域。
- 尺寸变化期间清空待发送滚动并暂停接收，串行同步最终尺寸；收到匹配网格的完整渲染帧且尺寸请求成功后恢复。输出包附带帧网格信息，不将局部帧当作尺寸已就绪。
- 切任务、切项目、卸载、断线和身份变化时清空队列及小数积累；不把旧事件迁移或重放到新连接。键盘和既有复制行为保留。
- 不新增 SQLite 表或迁移；新增提示遵循稳定翻译键及中文回退约定。
- 提供显式 Herdr 可执行文件环境覆盖，用于隔离验收；未设置时沿用当前安装路径。错误的覆盖路径应失败，不静默改连其他程序。
- 开发完成同步代码结构文档和实际验收记录。

## Testing Decisions

- 用户已确认的主要入口仍是：真实 Windows 看板滚轮 → Tauri → Herdr → Codex CLI 可见内容变化；使用专用测试 session、任务、数据库和 Codex 配置。
- 核心断言由原“滚轮无反应/只移动约一行”收紧为“一格滚轮约六行，反方向可返回”。检查可见编号输出的范围，不仅检查 IPC 次数。
- 复用现有看板/终端组件测试边界，补充步长、小增量、反向、队列失效、字符区边界、等待匹配渲染尺寸及键盘回归。xterm 与 Tauri 替身只证明前端路由，不能代替真实桌面验收。
- 真实 Herdr/Codex 另验证应用内部滚动与宿主历史回滚；覆盖连续滚动、返回底部、面板/字号变化、切换任务、断线重连及键盘输入保留。
- 执行前端测试、类型检查、生产构建与 Rust 测试，清理临时调试日志，按固定基点执行 Standards/Spec 审查，并仅提交本次范围。
- 真实系统 DPI 切换因电脑控制工具拒绝访问 Windows Settings 未执行；不得把浏览器模拟缩放写成实际 DPI 验收。取消点击要求后，这项限制记录保留，不阻断本次滚轮步长修复交付。

## Out of Scope

- 鼠标点击、按下/抬起、拖动、悬停及链接转发；此前这部分要求已由用户取消。
- 为点击而升级 Herdr、替换用户的默认安装或重启其共享 server。
- 任务派发、生命周期、会话恢复、数据库结构及其他看板功能调整。
- 新增滚动设置面板、全局偏好、历史搜索或导出。

## Further Notes

- 先前隔离验收数据已证明：旧接入方式发出较大的行数，实际应用仅移动约一行；本次修复必须对真实应用生效。
- 旧版与新版 Herdr 都存在应用滚轮忽略 `lines` 的路由，批量单行命令避免依赖最新点击协议。
- 规格、实现、模拟验证、真实桌面验证和部署分别记录；未替换用户正在运行的看板二进制。
